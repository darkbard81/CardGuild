# M12-5 — 첫 전투와 미네르바의 길드 안내

관련 이슈: [#67 Tutorial Chapter 1](https://github.com/darkbard81/CardGuild/issues/67). 이 문서는 첫 전투에 대한 합의와 대사, 구현 범위를 기록한다. #67 전체 완료를 의미하지 않는다.

## 첫 전투의 선행 계약

- 주인공과 모집 동료 모두 무기 카드 1장 + 클래스에 어울리는 레벨 1 준비 카드 1장, 총 2장으로 시작한다. 별도 기본 지급 카드는 제거한다.
- 모든 초기 무기는 피해를 주는 공격 카드 정확히 1장을 제공한다. 기존 할버드의 Trip도 공격형 기술로 대체한다. 무기별 이름·비용·세부 효과는 아래 구현 항목에 기록한다.
- 준비 용량은 유지하고 이후 보상으로 덱을 확장한다. 초기 장비에서 추가 카드가 나오지 않도록 Aerin의 비행 장화도 정리한다. 기본 공격·이동·방패 올리기는 기존 기본 행동 계약을 유지한다.
- 초기 준비 카드는 Bard Soothe, Champion Lay on Hands, Cleric Heal, Druid Frostbite, Fighter Vicious Swing, Ranger Aimed Shot, Rogue Careful Advance, Witch Fear, Wizard Force Barrage다. 레벨 1은 현재 CardGuild 카드 데이터 기준이다.
- 1-1은 레벨 −1 슬라임 여성과의 연습전이다. 낮은 능력치만으로 생존을 보장하지 않고, 이 전투에만 주인공 HP가 1 아래로 내려가지 않는 명시적인 길드 보호를 적용한다. 적 능력치는 아래 구현 항목에 기록한다.

## 전투 전 대화

설명의 목적은 첫 전투 전에 **상대 → 시작 카드 → 행동과 방향 → 연습전 보호 → 시작 격려**를 짧게 안내하는 것이다. 실제 게임 연결은 아래 선행 조건을 충족한 첫 연습전에 한정한다.

화자는 기존 길드 안내원 **미네르바**(`speakerId: minerva`)다. 새 캐릭터나 표정 이미지를 만들지 않고 기존 페이스 시트와 독립 씬 플레이어를 재사용한다. 생성 전 환영 대화와 구분되는 씬 ID는 `guild-first-battle-briefing`으로 한다.

캐릭터 생성·저장이 완료된 뒤 첫 전투 준비 화면에서 시작을 선택하면, 전투를 실제로 시작하기 전에 아래 대화를 표시한다.

| 페이지 | 표정 ID | 대사 |
| --- | --- | --- |
| 1 | `welcome` | 첫 전투는 길드의 연습 상대인 슬라임과 함께할 거예요. 서두르지 말고, 모험가님의 힘을 하나씩 익혀보세요. |
| 2 | `explain` | 처음에는 무기로 사용하는 공격 카드 한 장과, 클래스에 맞는 준비 카드 한 장이 주어져요. 기본 공격과 이동은 카드 없이도 할 수 있답니다. |
| 3 | `explain` | 자기 턴에는 행동을 세 번 할 수 있어요. 카드마다 필요한 행동 수가 다르니 내용을 확인해보세요. 턴을 마칠 때는 바라볼 방향도 골라주세요. |
| 4 | `firm` | 이번 연습전에서는 길드의 보호로 HP가 1보다 낮아지지 않아요. 이 보호는 길드의 두 연습전에만 적용된다는 점을 기억해주세요. |
| 5 | `cheer` | 실수해도 괜찮아요. 무기와 카드를 직접 사용해보면서 익혀보세요. 준비되셨다면 시작해볼까요? |

## 진입과 종료 동작

- 반투명 하단 대화창을 전장 미리보기 위에 표시한다. 화면 어디든 클릭·터치 또는 Enter/Space로 진행하고 마지막 페이지에서 같은 입력으로 완료한다. 돌아가기·다음·마지막 확정 버튼은 없다. 완료 또는 `건너뛰기`에서 호출자가 전투 시작을 요청한다. 대화를 읽는 동안 서버 전투/적 턴을 시작하지 않는다.
- Escape는 첫 전투 준비 화면으로 돌아가고 시작 버튼에 포커스를 둔다. 새 캐릭터와 작성·저장된 준비 정보는 유지한다. 생성 전 환영 대화처럼 계정 시작 화면으로 보내지 않는다.
- 취소 후 다시 시작을 선택하면 대화를 처음부터 보여준다. 완료/건너뛰기 후 같은 진입 시도의 시작 요청 오류·재시도에서는 반복하지 않는다. 완료 기억은 클라이언트의 해당 진입 시도에만 두고 Save/계정에 영구 읽음 필드를 추가하지 않는다.
- 실제 전투에 진입한 뒤 재연결·전투 Resume에는 끼워 넣지 않는다. 다음 Encounter나 Guest 참가에 반복하지 않는다. 설명 완료가 게임 규칙상의 출전 조건이나 서버 권한 검사를 우회하지 않는다.
- 중복 진행·완료로 전투 시작 요청을 두 번 보내지 않는다. 대화 중 세션 종료나 다른 상태로의 전환이 발생하면 대화를 닫고 오래된 시작 요청을 보내지 않는다.

## 연결 조건과 검증

이 대사는 **2장 초기 덱·레벨 −1 슬라임·실제 HP 보호가 모두 구현된 신규 1-1에만 연결한다**. 현재 Goblin Trouble에 보호를 약속하는 대사를 먼저 노출하지 않는다. 보호는 설명의 존재나 클라이언트의 읽음 상태에 의존하지 않고 authoritative 전투 규칙이 보장한다. 전투 화면에도 이 연습전의 보호가 적용 중임을 표시한다.

- 콘텐츠 검사: 5개 대사의 화자·표정 ID가 실제 페이스 목록에서 해석된다.
- Interaction: 첫 전투 시작 → 대화 → 완료/건너뛰기 → 시작 요청 한 번, 취소/Escape → 준비 화면과 포커스, 요청 오류 재시도 시 대화 생략을 확인한다. 대화 중 세션 종료·전투 진입 시 오래된 요청도 차단한다.
- Domain: 장시간 행동하지 않거나 연속 공격·치명타를 받아도 보호 전투에서 HP ≥ 1, 보호 없는 전투에서는 정상 피해/전투불능을 검증한다. 대사 테스트로 HP 보호 검증을 대신하지 않는다.
- J-START: 생성 전 환영 → 실제 생성·저장 → 첫 전투 준비 → 미네르바 설명 → 신규 1-1의 실제 행동 연결을 확인한다. 이미 진행 중인 전투의 이어하기에 설명이 재삽입되지 않는지도 기존 복구 흐름에서 보호한다.

구현 검증은 저장소의 최종 gate와 콘텐츠 플레이 검토로 수행한다.

## 구현 상태와 후속 범위

현재 작업 브랜치에서 기존 모험의 첫 전투를 `encounter.guild-practice`로 교체한다. 이후 7개 전투와 모집 검증용 별도 Adventure는 유지하며, #67 전체 Tutorial Chapter 전환을 완료한 것으로 취급하지 않는다.

- 슬라임: 레벨 −1, HP 12, AC 12, 속도 15ft, 공격 +2, 피해 1d4 bludgeoning. 첫 연습전의 모든 아군은 공통 피해 처리에서 HP 1 하한을 적용받는다. 대화·클라이언트 상태와 무관하며 저장 복구에서도 시나리오 정의와 일치해야 한다.
- 시작 무기 공격: Light Blade → Quick Cut(1행동, 적중 시 1d2 추가 피해), Guardian Mace → Heavy Blow(2행동, 무기 주사위 +1, MAP 2회), Staff → Guarding Blow(1행동, 치명타 시 자신에게 Parrying), Composite Shortbow → Piercing Shot(1행동, 적중 시 1d2 추가 피해), Halberd → Hooking Cut(1행동, 치명타 시 넘어뜨림). 추가 피해는 치명타 시 두 배다.
- 초기 지급에서 빠진 기존 카드는 이후 보상 선택지로 이동한다. Aerin의 비행 장화도 후반 보상으로 이동한다. 기존 일러스트는 새 무기 카드에 재사용하며 `card-art-plan.json`에 원본 출처를 남긴다.
- 미네르바 설명은 보호가 있는 첫 전투에만 연결한다. 준비 화면의 출전 오류를 표시하고, 이미 설명을 완료한 동일 시도의 요청 재시도에서는 설명을 반복하지 않는다.
- 최종 로컬 gate `CI=true npm run check && CI=true npm run test:all` 통과: Domain 131, Integration 23, Interaction 64, Journey 4, 총 222개. 첫 연습전 시작·승리·성장·협동·서버 재시작 후 이어하기를 포함한다. 실물 iPad/Safari와 GitHub CI는 미실행이다.

#68에서 보호 범위를 1-2 상태 대응 훈련까지 확장했다. 상세 계약은 [M12-6](m12-6-prone-training.md)에 있다. 위 222개 gate 결과는 #67 구현 당시 기록이다.
